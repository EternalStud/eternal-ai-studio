# Eternal AI Studio — Real-World AI Revenue Lab

> **Can an AI + Apple Mac Mini (M2) + Burst Cloud GPU actually produce high-retention, monetizable explainers and tutorials worthy of real audience trust?**  
> This repository is our transparent, evidence-driven creative engineering laboratory.

## Core Rules of This Lab
1. **Zero Teacher/Student Monetization:** All education/teacher tools on `uhskaparpurakanti.in` stay 100% free. This repo is strictly for **public media, high-craft explainers, and scalable creative workflows**.
2. **Topic-First Skill Routing ("Fit Before Flash"):** Before writing a single script or opening Blender, analyse the topic to choose the right visual medium (Blender 3D *only* for physical/spatial storytelling, bespoke Canvas/HTML5 motion graphics for live algorithms/maps/data systems, real zoomed screencasts for tutorials). Never stretch repetitive visual loops over unrelated narration.
3. **Human-Grade Audio First:** Use the creator's cleaned mic audio for screen tutorials, or our verified dual-voice Hinglish stack (`Chatterbox` `Notebook LLM hindi` male + `Veena` `kavya` female) with RMS silence trimming and `-14 LUFS` mastering.
4. **Full Session Continuity:** Every experiment, render architecture, critique, and next step is logged in [`RESUME_HERE.md`](./RESUME_HERE.md).
